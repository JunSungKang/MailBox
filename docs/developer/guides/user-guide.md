# MailBox 사용자 안내

## 웹메일 접속

운영 Webmail은 `https://<MAIL_WEB_HOSTNAME>:18443`에서 접속한다. 포트는 `MAIL_WEB_HTTPS_PORT` 값을 따르며 HTTP `18080`은 HTTPS로 이동한다. 로컬 CA를 사용하는 설치는 운영자가 제공한 공개 CA 인증서를 접속 기기에 신뢰 등록해야 한다. 개발 실행은 `http://localhost:18080`을 사용한다.

화면은 밝은 진주색, 민트·라벤더 빛과 반투명 패널로 구성한 **내일의 우편함** 테마를 사용한다. 로그인 화면의 문구는 “내일이 먼저 말을 걸어오는 곳”이며, 메일 목록의 날짜는 실제 수신·발송 시간을 표시한다. 기기의 동작 줄이기 설정을 켜면 장식 효과의 움직임이 줄어든다.

사용할 사용자 ID, 12자 이상이며 UTF-8 기준 72바이트 이하인 비밀번호, 운영자에게 받은 가입 코드로 계정을 만든다. 한글은 보통 한 글자에 3바이트이므로 24자까지 사용할 수 있다. Webmail·IMAP·SMTP가 같은 비밀번호를 사용하므로 인증 형식에서 허용하지 않는 NUL(널) 문자는 사용할 수 없다. 사용자 ID는 `.` 또는 `..`로 지정할 수 없다. 가입이 완료되면 Webmail·IMAP 로그인 계정과 운영자가 허용한 domain의 SMTP 수신 주소가 함께 생성된다.

이전 `users.json` 계정은 같은 ID와 기존 비밀번호로 다시 가입해야 이전할 수 있다. 가입 코드만으로 다른 사용자의 기존 ID를 사용할 수 없다. 기존 비밀번호가 72바이트를 넘거나 NUL 문자를 포함하거나 계정 정보가 손상된 경우 운영자에게 소유권 확인을 거친 이전을 요청한다. 이미 Dovecot 계정으로 전환한 사용자의 로그인과 비밀번호는 유지된다.

## 메일함

- `받은 편지`: 수신 메일
- `보낸 편지`: 웹메일에서 발송한 메일
- `돌아온 편지`: 반송 또는 실패 메일

## 메일 작성

`편지 쓰기` 화면에서 수신자, 제목, 본문을 입력하고 발송한다. domain을 생략한 수신자는 `MAIL_DEFAULT_DOMAIN`이 붙는다. 발신 주소는 로그인 사용자와 기본 domain으로 고정된다.

## IMAP 접속

기본 IMAP 접속 정보는 다음과 같다.

- 서버: 설치 서버 주소
- 포트: `143`
- 연결 보안: `STARTTLS` (TLS 1.2 이상)
- 사용자: Webmail에서 가입한 사용자 ID
- 비밀번호: Webmail 가입 시 설정한 비밀번호

STARTTLS 연결 후 로그인한다. 메일 클라이언트의 서버 주소는 인증서에 포함된 domain 또는 IP와 일치해야 한다. SMTP `25`는 서버 간 수신용이며, 편지는 Webmail의 `편지 쓰기`에서 발송한다.

메일은 암호화와 서버 인증서 검증을 통과한 SMTP 경로로 발송한다. 상대 메일 서버가 이를 지원하지 않으면 지연될 수 있으며 운영자가 큐 상태를 확인해야 한다. Webmail의 “접수 완료”는 Postfix 접수를 뜻하며 상대편 최종 배달 보장은 아니다.
