# MailBox 사용자 안내

## 웹메일 접속

브라우저에서 `http://<server>:18080`에 접속한다. 포트를 변경한 경우 `.env`의 `MAIL_WEB_PORT` 값을 기준으로 접속한다. 사용할 사용자 ID, 12자 이상의 비밀번호, 운영자에게 받은 가입 코드로 계정을 만든다. 가입이 완료되면 Webmail·IMAP 로그인 계정과 운영자가 허용한 domain의 SMTP 수신 주소가 함께 생성된다.

## 메일함

- `받은 편지`: 수신 메일
- `보낸 편지`: 웹메일에서 발송한 메일
- `돌아온 편지`: 반송 또는 실패 메일

## 메일 작성

`편지 쓰기` 화면에서 수신자, 제목, 본문을 입력하고 발송한다. domain을 생략한 수신자는 `MAIL_DEFAULT_DOMAIN`이 붙는다. 발신 주소는 로그인 사용자와 기본 domain으로 고정된다.

## IMAP 접속

기본 IMAP 접속 정보는 다음과 같다.

- 서버: 설치 서버 주소
- 포트: `143`
- 사용자: Webmail에서 가입한 사용자 ID
- 비밀번호: Webmail 가입 시 설정한 비밀번호
